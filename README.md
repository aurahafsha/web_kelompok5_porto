# Website Portofolio Karya Siswa RPL – Kelompok 5

Kelompok 5 · XII RPL · SMK NEGERI 1 PURWOSARI
Guru pembimbing: Veny Wulandari

Dibangun dengan Laravel dan MySQL (XAMPP).

## Mulai cepat

Ikuti panduan lengkap di `docs/SETUP-LARAVEL.md`. Ringkasannya:

    composer install
    copy .env.example .env
    php artisan key:generate
    php artisan migrate
    php artisan storage:link
    php artisan serve
